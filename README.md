# 📚 تطبيق تعلم العربية لغير الناطقين بها (Arabic Learning PWA)

تطبيق ويب تفاعلي حديث (Progressive Web App) مصمم لمساعدة غير الناطقين باللغة العربية على تعلم المفردات، واختبار النطق الصوتي، وتتبع تقدمهم التعليمي بطريقة ممتعة وتفاعلية تشبه الألعاب.

---

## ✨ المميزات الرئيسية

* **🎨 واجهة عصرية متجاوبة:** مصممة باستخدام **Bootstrap 5 (RTL)** لضمان تجربة مستخدم سلسة على جميع الأجهزة والهواتف الذكية.
* **⭐ نظام التلعيب وحفظ التقدم:** حفظ النقاط والمستويات تدريجياً باستخدام `LocalStorage` وفتح الأقسام المغلقة عند إتمام الدروس.
* **🎴 بطاقات مفردات ثلاثية الأبعاد (3D Flashcards):** بطاقات تفاعلية تعرض الكلمات مع صور تعبيرية وترجمتها الإنجليزية بقلب سلس.
* **🎙️ تقييم النطق الصوتي الذكي:** مدعوم بـ **Web Speech API** للاستماع لصوت المتعلم ومقارنته بالكلمة المستهدفة وتقييمه فورياً.
* **📱 دعم PWA (التطبيق التقدمي):** إمكانية تثبيت التطبيق على شاشة الهاتف الرئيسية أو سطح المكتب والعمل **بدون إنترنت (Offline Mode)** بفضل `Service Worker`.

---

## 🛠️ التقنيات المستخدمة

* **HTML5 / CSS3 / JavaScript (ES6+)**
* **Bootstrap 5 (RTL)** - لتصميم الواجهات والتجاوب.
* **Howler.js** - لإدارة وتشغيل الملفات الصوتية.
* **Web Speech API** - للتعرف على الصوت وتقييم النطق.
* **PWA (Manifest & Service Workers)** - لدعم التثبيت والعمل دون اتصال.

---

## 🚀 هيكل المشروع (ملفات المجلد)

يتميز المشروع ببساطته وعدم حاجته لأي أدوات بناء معقدة، حيث يتكون من مجلد رئيسي يضم الملفات التالية:

```text
├── index.html       # الواجهة الرئيسية وكل الأكواد التفاعلية
├── manifest.json    # ملف تعريف تطبيق الـ PWA
└── sw.js            # ملف خدمة التشغيل للتخزين المؤقت والعمل دون إنترنت
```
